# PDF 参考文献能力补充

PRD V1.0 为 2026-10-20 版本快照，当时的文献能力为手动标题与笔记。后续 Demo 于 10 月 21 日扩展为 PDF 上传与文字检索，以下为当前实现范围。

- 上传可读 PDF 后自动识别标题，提取正文并保留原页码；标题可修改，笔记可空。
- 单份最大 10 MiB、80 页；每课题最多 50 篇。零文献时保留上传入口与直接创建入口。
- 文本按页分块并以关键词选取相关片段，交给当前模型分析；不声称每轮读完全部页面。
- 原文件与提取文字存于本机数据库。仅将本轮选中的相关片段发送至模型服务。
- 格式错误、超限、不可读文件需说明原因；扫描件无 OCR。加密 PDF 提示不准确已记录为已知问题 F08。
- 文献仅作研究背景，汇报中的用户成果仍只依据期间用户发言。

文献编辑与删除的保存边界仍有 F04 问题，详情见[测试说明](../testing/README.md)。
